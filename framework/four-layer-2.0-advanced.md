# 四層判斷法 2.0：它的天花板，與更進階的廣告判斷框架

> 這份文件假設你已讀過 [`four-layer-method.md`](four-layer-method.md)。它不推翻四層判斷法，而是誠實指出它撐得住哪裡、撐不住哪裡，並補上 2024–2026 業界已在用、四層沒涵蓋的判斷框架。讀完你會知道：四層判斷法該擺在工具箱哪一格，什麼時候要換更大的扳手。
>
> ⚠️ **數字皆為「跨品類經驗區間」，非官方定律。** 全文出現的百分比（高估係數、CPA 影響、iROAS 折扣、Hook rate 門檻等）來自分散的第三方 case study／社群經驗，量級方向可信但會因品類、客單價、毛利、帳戶大小差很多。**請一律用你自己帳戶的歷史推自己的數字，勿照搬。** 唯一該錨定的常數是 `打平 ROAS = 1 ÷ 貢獻毛利率`。

## 一、四層判斷法寫得好嗎？（誠實總評）

結論：**作為「教 1–3 年投手用 AI 讀 CSV」的入門框架，它寫得相當好。** 但有一個無法靠內部優化解決的結構性天花板——它整套建立在「平台回報的 CSV 數字可信」這個前提上，而這個前提在 2025–2026 已被打穿。

### 它的真正價值

1. **把「順序」講對了**——結構→表現→趨勢→決策，由粗到細，先看大盤再看單組。新手最常犯的錯就是盯著某組漂亮 ROAS 加碼，卻沒發現它只佔 2% 預算。光這個「順序」裝置就值回票價。
2. **診斷矩陣是全篇最值錢的部分**——「CTR 高 + CVR 低 → 改落地頁不是改素材」這種「兩指標一起看才知根因」，正是資深和新手的差距。
3. **對雜訊的警覺心成熟**——學習期、編輯重置、檔期、樣本量 < 30，擋掉了新手大量「看到一天掉量就關組」的自殘操作。
4. **適合的人很明確**——1–3 年投手、品牌內部行銷、電商自營小團隊，月花數萬到數十萬、單一 Meta 帳戶、零程式門檻。在這畫像內它好用。

### 它的天花板與盲點（4 個，不客套）

**盲點 1（最致命）：建立在「平台 ROAS 可信」的流沙上。**
四層所有門檻（ROAS ≥ 3× 健康、< 1× 關閉）都假設 CSV 的 ROAS 是真的。但平台 ROAS 受**歸因窗**灌水：預設「7 天點擊 + 1 天瀏覽」會把「只是滑過看到、本來就要買」的人算成廣告功勞。多數第三方審計指出 view-through 灌水可觀（常見區間約 ＋兩到三成，品類差異大），跨渠道各自回報的轉換加總常超過實際營收（同一筆訂單被重複算）。**結果：你照四層把預算加給「ROAS 11× 的再行銷組」，可能加給的是一個真實增量很低的灌水組；被你砍掉的「ROAS 0.8× 新客引流」反而有正增量。四層會讓你有紀律地搬錯方向。**

**盲點 2：只看單帳戶逐組 ROAS，看不到「大盤賺不賺」。**
逐組 ROAS 全綠，不代表 MER（整體營收 ÷ 整體廣告花費）健康——自然流量、回購、跨渠道交互都沒進到單組 ROAS。四層缺一個「大盤層」，這是它從「投手工具」升級成「老闆能看的決策系統」缺的一塊。

**盲點 3：Advantage+/broad 時代，第 1 層（結構層）正在失效。**
第 1 層教你看「受眾/版位佔比」，但跑 Advantage+ Shopping（ASC）時受眾你沒在分、版位 Meta 自動配——這層在問一個你已沒控制權的問題。Andromeda（Meta 2024 年底公布、2025 年陸續部署的廣告推薦系統升級）之後，槓桿從「受眾設定」移到「素材角度多樣性」，四層沒有「素材角度」這個維度。

**盲點 4：相關性 vs 因果性——四層只能做到相關。**
「ROAS 高就加、低就減」是相關性判斷，無法回答唯一真正重要的問題：「這筆花費是不是帶來原本不會發生的銷售？」這不是優化能補的，要靠 holdout/增量測量這套不同的方法論。

> **一句話總評**：四層判斷法是一台**校準良好的羅盤**——指針穩、邏輯清、新手照著走不會迷路。但如果**地圖本身（平台回報數字）是錯的**，羅盤再準也會帶你走到坑裡。它需要的不是更好的指針，是先校準地圖。

## 二、四層判斷法該補的洞（具體修正）

| # | 問題 | 怎麼改 |
|---|---|---|
| 1 | 所有 ROAS 門檻都假設數字可信，沒先問「這 ROAS 是哪個歸因窗算的」 | **加「第 0 步：確認歸因設定」**。全帳戶固定同一歸因窗，並同時匯出 `1d-click`（保守）vs `7d-click/1d-view`（寬鬆）兩版對照；用後台真實訂單／GA4 對帳，算出帳戶的高估係數 |
| 2 | 「ROAS ≥ 3× 健康」對灌水嚴重的再行銷組是錯的 | 健康區間表加一欄「**渠道增量折扣係數**」（新客接近 1、再行銷常較低）；健康判定改成 `平台 ROAS × 折扣係數 ≥ 打平點` |
| 3 | 4-3「從 ROAS 0.8× 搬到 ROAS 11×」——但平均 ROAS 11× 可能已飽和 | **搬錢排序鍵從「平均 ROAS」改成「mROAS」**：釋出預算搬給「mROAS 最高且未飽和」的組 |
| 4 | 「連 7 天 ROAS > 目標就加碼」——平均 ROAS 高不代表加得動 | 加碼拆兩段：(1) 平均 ROAS > 目標（值得） → (2) **上次加碼 mROAS ≥ 打平點**（加得動）才加。用「階梯測試」逼近飽和點 |
| 5 | broad/ASC 帳戶下「受眾/版位佔比」是黑盒子 | 第 1 層升級「**雙軌結構**」：除預算佔比，加「素材角度盤點」；80% 花費壓同一賣點 → 標「角度過度集中」 |
| 6 | 診斷矩陣最細只到落地頁，看不進影片內部 | 矩陣最上面加兩列，形成五層漏斗 **Hook→Hold→CTR→CVR→ROAS**；匯出時帶「3 秒播放」「ThruPlay」。圖片素材直接從 CTR 起算 |
| 7 | 第 3 層判定「真衰退」後只導向減/關，但最常見根因是素材燒完 | 衰退後多問一題：是**素材疲乏**（CTR↓ + Frequency↑ + CPM↑ 三者同向）還是帳戶問題？確診疲乏 → 第三條路「**換素材後維持預算**」 |
| 8 | 四層用「破壞效應」指「編輯打回學習期」，與 Meta 官方 Breakdown Effect 同名不同義 | 四層內部正名為「**編輯重置效應 / Edit Reset**」。另註明：Meta 官方 **Breakdown Effect** 廣義指「彙總層與細分層（版位/年齡/CBO 各組）指標出現矛盾」的加權平均假象（Simpson's Paradox 廣告版），CBO 預算分配只是它最常被引用的案例之一 |

> 關於修正 1 的門檻：若實測帳戶平均高估約 1.5 倍，第 2 層健康門檻可相應上調（如 3× → 約 4.5×）。**但這是參考做法不是公式**——上調過頭會誤砍其實健康的組，務必用自己對帳出來的係數，且寧可分階段試調。

## 三、更進階／互補的廣告判斷框架

六組框架不取代四層，是補它的不同樓層。

### (1) 獲利導向：MER / Blended ROAS / 貢獻毛利 / NCAC

**是什麼**：把判斷單位從「單一廣告組」拉高到「整個生意」。
- **MER（Marketing Efficiency Ratio）= 總營收 ÷ 總廣告花費**。不管渠道、不管歸因，就看「所有錢進來 ÷ 所有廣告錢出去」。
- **Blended ROAS**：同概念，但有人只算廣告費、有人納入所有行銷成本——定義因人而異，先講清楚。
- **貢獻毛利 = 營收 − COGS − 金流 − 物流 − 廣告**。這才是「真的有沒有賺」。
- **NCAC（新客獲取成本）= 廣告花費 ÷ 新客數**。擠掉再行銷攔截老客的灌水，只看「花多少買到一個全新的人」。

**怎麼判斷加/減/關**：
- **MER 打平點 = 1 ÷ 貢獻毛利率**。但**用滾動趨勢看，不是單日剎車**——看 7/14 日滾動 MER，並區分「拉新期可接受的較低 MER」與「穩態 MER」。
- 看 **NCAC 而非 blended CPA**：blended CPA 漂亮但 NCAC 一直升 = 你在靠再行銷吃老本，新客越買越貴。這正是四層第 1 層「再行銷 > 30%」想抓但抓不準的東西，NCAC 給了量化指標。

```
MER = 總營收 ÷ 總廣告花費
MER 打平點 = 1 ÷ 貢獻毛利率
NCAC = 廣告花費 ÷ 新客數
```

**何時比四層好**：老闆問「這個月到底賺不賺」、或「逐組 ROAS 全綠但帳戶現金一直在掉」時。逐組 ROAS 是顯微鏡，MER 是體溫計。

**怎麼並用**：**MER 當煞車，四層當方向盤。** 但煞車是「趨勢級」的——**滾動 MER 持續跌破打平帶、且非由拉新投資造成時，才收緊大盤預算；單日跌破先當噪音。** 別在剛起量或品牌拉新的關鍵期，因單日 MER 低就一刀切停掉成長投資（拉新期 MER 本來就低）。

### (2) 增量測量：Incrementality / Holdout / iROAS / Geo-lift

**是什麼**：用「對照組／反事實」回答四層回答不了的問題——「有投 vs 沒投的差值是多少」。
- **Holdout（對照組）**：隨機切出一部分人，測試期完全不給看廣告，當「沒有廣告的世界」樣本。
- **Incrementality（增量）= 試驗組轉換 − 對照組轉換**。只有這塊是廣告真正的功勞。
- **iROAS（增量 ROAS）= 增量銷售額 ÷ 廣告花費**。把分子從「平台宣稱轉換」換成「實測增量」。
- **Geo-lift**：用「地區」當實驗單位（投 vs 不投），用合成對照估增量，繞過 cookie/像素黑洞。

**怎麼判斷加/減/關**：
- iROAS ≥ 打平點 → 真賺、可加；< 打平點 → 帳面賺實際賠、該減；≈ 0 → 純搶功勞、關掉。
- 多數第三方報告指出 iROAS 常明顯低於平台 ROAS（區間視品類差異大，再行銷組落差尤其明顯）。

```
Lift% = (試驗組轉換率 − 對照組轉換率) ÷ 對照組轉換率
iROAS = 增量銷售額 ÷ 廣告花費
holdout 比例：高轉換量 5–10%、低轉換量 15–20%
檢定力：研究期內總轉換量太少（雜訊吞訊號）就別做
```

> 🚨 **低量帳戶的硬護欄（台灣多數中小電商日轉換個位數）**：**不要**用「暫停某組、看銷售有沒有掉」當砍組依據——統計檢定力不足時，「銷售沒掉」極可能只是雜訊，照做會砍掉其實有效的組、燒掉有效預算。**只有研究期內總轉換達檢定力門檻（量級上看數百至上萬筆）時，holdout 結論才成立。** 量不夠就別做用戶級 holdout，改用「平台 ROAS × 保守折扣係數」估一個 proxy iROAS，並維持多週觀察。Geo-lift 在台灣（地區小、跨區流動大）也不易切乾淨。**這套是「季度校準」，不是天天跑。**

**怎麼並用**：日常用四層開源節流；每季對「佔預算最大、ROAS 漂亮到不真實」的再行銷/品牌字組做一次校準，得出該渠道「增量折扣係數」寫回第 2 層。符合資格（轉換量/帳戶等級）的帳戶，可在 Ads Manager 啟用 **Incremental Attribution** 作為最佳化/歸因設定——**但開放程度依帳戶與地區而異，多數小帳戶尚無此選項**；啟用後帳面 ROAS 會下降（擠水分非變差），先跟決策者溝通。

### (3) 邊際與飽和：mROAS / 飽和曲線 / Adstock / MMM

**是什麼**：回答「下一塊錢該往哪加、加多少、加到哪要停」。
- **mROAS（邊際 ROAS）= Δ轉換金額 ÷ Δ花費**。平均 ROAS 看「整體值不值」，mROAS 看「再加 1 元值不值」。一組可平均 4× 但 mROAS 只剩 0.6×（已餵飽，再加是賠的）。
- **飽和曲線（S 曲線）**：花費→報酬非線性，越往後越平。曲線斜率就是 mROAS，拐點是該停止加碼的最佳預算點。
- **Adstock（延續效應）**：廣告效果有尾巴，今天看到的人可能 3 天後才下單。解釋「關掉廣告隔天訂單不會歸零」「加碼當天 ROAS 沒馬上反映」。
- **MMM（行銷組合模型，如 Meta Robyn / Google Meridian）**：用迴歸把各渠道花費對總營收做歷史拆解，內建 adstock + 飽和，不靠像素。

**怎麼判斷加/減/關**：**等邊際原理**——最佳配置是把所有組的 mROAS 拉到同一條水平線，且都 ≥ 打平點。只要 A 組 mROAS > B 組，從 B 搬 1 元到 A 就必賺。

```
mROAS = Δ轉換金額 ÷ Δ花費（兩個觀測期相減）
停止加碼點：mROAS 下降到 ≈ 打平 ROAS（= 1 ÷ 毛利率）
搬錢規則：mROAS_A > mROAS_B → 從 B 搬到 A，直到相等
階梯測試：用「目前 / +20% / +40%」三級測 mROAS，哪級開始陡降就接近飽和
```

**何時比四層好**：帳戶已過「止血/搬錢/微調」、主力組都健康、要決定「再投 10 萬往哪加」時。

> ⚠️ MMM 門檻很高（要 1–2 年週級資料 + 資料科學能力），**絕大多數台灣中小電商現階段不適合自建**。先理解「飽和 + 邊際」觀念、用「3 點階梯測試」手動逼近飽和點，CP 值遠高於硬上 MMM。

### (4) Meta 原生：Advantage+ / 帳戶精簡 / 學習期

**是什麼**：Andromeda 之後，Meta 的邏輯是「AI 看懂素材→自動配對受眾」，所以官方主張結構簡化（少 campaign、少 ad set、broad 受眾、集中訊號），讓系統有足夠轉換量退出學習期。

**怎麼判斷加/減/關**：
- **學習期**：ad set 在編輯後需累積**約 50 次「最佳化事件」**（optimization events，依該組最佳化目標而定，**不一定是購買**，可能是加購、連結點擊等）才退出學習期；通常建議 7 天內達成，否則會被標記 **Learning Limited**。⚠️ 別把「50 / 7 天購買」當硬公式。
- **帳戶精簡**：某 ad set 長期湊不到足夠最佳化事件 → 不是廣告爛，是**切太細**，該合併集中。
- **CBO Breakdown Effect**：看到系統把錢分給當下 CPA 較高的組，先看 campaign **總** ROAS，健康就別手動干預。

```
退出學習期：約 50 次最佳化事件（非必為購買；通常望 7 天內達成，否則 Learning Limited）
加碼上限：常見社群經驗法則 ≤ 20–25% / 24–48h（非 Meta 官方公開門檻）
規模化節奏：每 2–3 天 +10–20%，分多次逼近
```

> ⚠️ 「≤ 20–25% / 48h」「學習期重置傷 CPA」都是**社群經驗法則**，Meta 官方只說大幅編輯會重置學習期、未給具體百分比上限。別把它當「沒到 25% 就絕對安全」的鐵律。

**何時比四層好**：帳戶已是 Advantage+/broad、第 1 層失效時。重點從「錢分得對不對」變成「結構夠不夠簡、訊號夠不夠集中」。

### (5) 創意漏斗診斷：Hook / Hold / CTR / CVR

**是什麼**：把一支影片拆成四關，逐格算「人在哪掉光」，定位問題出在素材哪一段。這是「創意版的診斷矩陣」。

**怎麼判斷加/減/關（逐層卡點 → 動作）**：
- Hook 低 → 前 1–3 秒不夠抓眼 → 換開場，別動後面。
- Hook 高 Hold 低 → 開頭騙到人、中段沒兌現 → 重剪中段、提前講 offer。
- Hook + Hold 好但 CTR 低 → 影片好看但沒給點擊理由 → 加明確 CTA。
- CTR 好 CVR 低 → 承諾與落地頁/價格不符 → 修落地頁（與四層診斷矩陣同源）。
- **心法**：Hook rate 是「分診指標」不是「成功指標」——用它快速淘汰明顯爛的，最終仍以 CPA/ROAS 定生死。

```
Hook rate = 3秒播放 ÷ 曝光    （跨品類經驗：30%+ 算強，<25% 待修）
Hold rate = 15秒播放 ÷ 3秒播放（冷流量 15–25% 健康）
⚠️ 分母定義各工具不一（曝光 vs 觸及 vs 3秒起算）；團隊內先統一定義再比較，此處採「÷曝光」為示範
創意疲乏確診：CTR 數日內↓ + Frequency↑ + CPM↑（三者同向）
```

**何時比四層好**：「某組 ROAS 掉了」但你需要知道「這支影片哪裡爛、下一支怎麼改」時。台灣電商現在大量靠 Reels/短影音，這個 ladder 是四層缺的那塊。

---

### (6) 決策節奏與 KPI Tree：創意測試框架 + 北極星拆解

**是什麼**：四層只講「已上線素材怎麼加減關」，沒講「新素材怎麼上、怎麼公平比、何時算測完」。這塊補上游。
- **創意測試**：用獨立 ABO 測新素材（每概念一個 ad set、同預算同天數做乾淨比較）→ 早期用 hook/CTR 快篩 → 後期用 CPA/ROAS 驗證 → winner 移進 CBO 放大。
- **KPI Tree**：把「營收/利潤」往下拆成「流量 × CVR × AOV × 回購」，每節點對應一個可動槓桿，避免只盯 ROAS 一個數字。

**怎麼判斷加/減/關**：
- **Kill criteria**：花到約 1× 目標 CPA 仍 0 轉換 → 關（但**別在學習期內**用這標準殺）。
- **測試樣本**：每變體至少累積數十轉換才分得出真贏家（比四層的 < 30 更嚴）；小帳戶請縮減同時測試的變體數（一次 2–3 個概念，而非 9 個）。
- **60-30-10 預算法**：60% 給已驗證 winner、30% 給 winner 的 iteration（保留致勝元素只換鉤子）、10% 給全新概念。

**怎麼並用**：接在四層**前面**當「素材供給層」。過關的 winner 才進入四層的成熟評估。加碼時 30% 一定留給 winner 的 iteration，避免單支 winner 一疲乏就沒得換（呼應四層第 1 層「只靠一支素材就沒得換」）。

> ⚠️ 「花 $X 或 N 轉換」的門檻是美國基準；台灣 CPA 較低時按比例下修。小帳戶一天轉換個位數，每變體要累積足夠樣本可能得跑兩週——寧可少測幾個概念、測乾淨，也別一次上九個然後每個都不夠樣本。

## 四、整合建議：四層判斷法 2.0 的樣貌

核心思想：**四層判斷法不被取代，是被「上下夾住」——上面加大盤校準，下面加素材供給，中間用增量擠水分。**

```
┌──────────────────────────────────────────────────────────┐
│ 第 -1 層 · 大盤煞車（看 7/14 日滾動趨勢，非單日）            │
│   滾動 MER ≥ 打平點 (1÷貢獻毛利率)？ NCAC 有沒有失控？        │
│   → 滾動 MER 持續跌破且非拉新造成 → 收緊大盤；單日跌破當噪音  │
├──────────────────────────────────────────────────────────┤
│ 第 0 層 · 校準衡量基準（每季一次）                          │
│   確認歸因窗；對主力組校準 → 算各渠道「增量折扣係數」         │
│   → 寫回下面的 ROAS 目標（低量帳戶用 proxy，別硬跑 holdout）  │
├──────────────────────────────────────────────────────────┤
│ 第 0.5 層 · 素材供給（每週）                                │
│   ABO 測新素材 → kill criteria 淘汰 → winner 進 CBO         │
│   60-30-10 預算法；Hook→Hold 先過關                         │
├──────────────────────────────────────────────────────────┤
│ ★ 第 1–4 層 · 原四層判斷法（每天跑，但吃「去水分」的數字）    │
│   結構（雙軌：預算佔比＋素材角度）                           │
│   表現（Hook→Hold→CTR→CVR→ROAS 五層漏斗）                 │
│   趨勢（衰退再分流：素材疲乏 vs 帳戶問題）                   │
│   決策（加碼/搬錢看 mROAS；編輯幅度走經驗法則、分多次）        │
├──────────────────────────────────────────────────────────┤
│ 第 5 層 · 增量驗證（每季回頭驗證重大決策）                   │
│   砍整條再行銷線前，量夠就看 holdout/iROAS；量不夠用 proxy   │
└──────────────────────────────────────────────────────────┘
```

### 口訣：「**大盤踩煞車，季度擠水分，每週餵素材，每天調四層。**」

### 什麼時候從「逐組 ROAS」切換到「大盤 MER + 創意測試」？

| 訊號 | 該用什麼 |
|---|---|
| 單帳戶、月花數萬–數十萬、自己分受眾 | 純四層（逐組 ROAS）就夠 |
| 逐組 ROAS 全綠但帳戶現金在掉 | 加第 -1 層 MER 煞車（看滾動趨勢） |
| 已上 Advantage+/broad、受眾自動配 | 第 1 層改看素材角度，主戰場移到第 0.5 層創意測試 |
| 再行銷佔比高、ROAS 漂亮到不真實 | 加第 0/5 層校準，擠水分（量夠才做 holdout） |
| 跨多渠道、月花百萬 | 上 MER + 季度 MMM，四層退居「FB 帳戶內部微調」 |

> 核心切換邏輯：**帳戶越大、渠道越多、越用自動化，判斷重心越往「大盤 MER + 創意供給」移，四層越退居「單帳戶內部的每日微調」。** 四層永遠有用，只是隨規模成長，它從「主框架」變成「2.0 裡的中間那層」。

## 五、一句話總結

**四層判斷法是一台校準良好的羅盤，新手照著走不會迷路——但 2025–2026 的廣告戰場，先校準地圖（用 MER 看大盤、用增量擠掉平台 ROAS 的水分）比把羅盤磨得更亮重要得多。所以別丟掉四層，把它前面加一層「大盤煞車」、後面加一層「增量驗證」，讓它從投手的每日工具，長成老闆敢看的決策系統。**
