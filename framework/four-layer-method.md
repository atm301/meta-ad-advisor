# 四層判斷法完整手冊：從看到動只要 5 步

> 這份文件是整套方法的核心。資深投手判讀廣告數據時，腦中跑的不是「感覺」，而是一套固定的逐層拆解流程。把這套流程寫清楚，你自己能照著判斷，AI 也能照著給出具體、可執行、可被追問的建議。
>
> **怎麼讀**：第一次從頭讀一遍建立全貌；之後當工具書查——卡在哪一層就翻哪一層。最後的[一頁速查表](#一頁速查表)可以印出來貼牆上。

```
第 1 層 結構層 → 第 2 層 表現層 → 第 3 層 趨勢層 → 第 4 層 決策層 → 立即行動
  錢分得          指標健            訊號是            哪組加             5 分鐘
  對不對           不健康            否同向            減關               下決定
```

**為什麼是這個順序？** 由粗到細、由整體到個別。先看錢分得對不對（結構），再看每組賺不賺錢（表現），接著看是真的變化還是雜訊（趨勢），最後才決定動作（決策）。跳過前面直接看單一指標，最容易見樹不見林——例如某組 ROAS 很漂亮，但它只佔 2% 預算，加碼它對大盤幾乎沒影響。

## 〇、先打底：指標字典

四層判斷都建立在這些指標上。AI 會自動幫你算，但你得看得懂、能核對。

| 指標 | 全名 | 公式 | 白話 | 越高越好？ |
|---|---|---|---|---|
| **CTR** | 點擊率 | 點擊 ÷ 曝光 | 圖文吸不吸引人點 | ✅ |
| **CVR** | 轉換率 | 轉換 ÷ 點擊 | 進站後有沒有下單 | ✅ |
| **CPA / CPS** | 單次轉換成本 | 花費 ÷ 轉換 | 每張訂單花多少廣告錢 | ❌ 越低越好 |
| **ROAS** | 廣告投報率 | 轉換金額 ÷ 花費 | 每花 1 元賺幾元 | ✅ |
| **CPC** | 每次點擊成本 | 花費 ÷ 點擊 | 買一個點擊多少錢 | ❌ 越低越好 |
| **CPM** | 每千次曝光成本 | 花費 ÷ 曝光 × 1000 | 觸及 1000 人多少錢 | ❌ 越低越好 |
| **AOV** | 平均客單價 | 轉換金額 ÷ 轉換 | 平均一張訂單金額 | ✅ |
| **Frequency** | 曝光頻次 | 曝光 ÷ 觸及人數 | 同一人平均看幾次 | 適中（過高=疲乏） |
| **mROAS** | 邊際 ROAS | Δ轉換金額 ÷ Δ花費 | 「再加 1 元」能多賺幾元 | ✅（加碼的真依據） |

> **關鍵心法**：ROAS 看「整體值不值得」，mROAS 看「下一塊錢該不該加」。一組 ROAS 5× 很好，但若它已經到量、再加錢的 mROAS 只剩 1.5×，那這 1 元加在別組更划算。決策層的「加碼」判斷，本質上看的是 mROAS。

## 第 1 層 · 結構層：預算分配是否合理

問的是「**錢分得對不對**」。先看比例，再看表現——比例錯了，個別組做得再好也救不回大盤。

### 1-1 三類佔比要平衡

| 類別 | 看什麼 | 過度集中的風險 |
|---|---|---|
| **受眾佔比** | 不同年齡、興趣、再行銷的預算比例 | 押單一受眾＝這受眾一疲乏，整個帳戶跟著垮 |
| **素材佔比** | 圖文、影音、輪播各佔多少花費 | 只靠一支素材＝它一疲乏就沒得換 |
| **版位佔比** | 動態消息、Story、Reels 的分配 | 漏掉某版位＝放棄那裡的低成本流量 |

**比例警訊**：任一組花費佔比 > 50% 就值得檢查。80% 預算壓在一組廣告組合上，不是策略，是賭博。

### 1-2 漏斗階段的預算分配（電商參考配比）

結構不只看「平不平均」，更要看「**漏斗各階段有沒有都餵到**」。只投轉換、不投引流，水池會越打越乾；只投引流、不投再行銷，等於把快成交的客人放生。

| 階段 | 廣告類型 | 參考佔比 | 目的 |
|---|---|---|---|
| 上層 | 引流／品牌曝光 | ~10% | 把新的人帶進池子 |
| 中層 | **主轉換** | ~70% | 下單轉換（主力火力） |
| 下層 | 再行銷 | ~15% | 補救加購未結帳、瀏覽未買 |
| 回流 | 回購／忠誠 | ~5% | 老客回購、口碑 |

> 這是「健康電商」的常見起點，不是鐵律。新品牌可能要多投引流（水池還小）；成熟品牌再行銷＋回購可以更重。重點是**四層都有錢，且比例說得出道理**。

### 1-3 結構層常見錯誤

- ❌ **只看絕對金額不看佔比**：花最多的那組不一定是問題，要看它佔比是否異常。
- ❌ **再行銷吃掉大半預算還沾沾自喜**：再行銷 ROAS 天生高（因為對的是已經想買的人），但它**規模有上限**——池子就這麼大。再行銷佔比過高（如 > 30%）通常代表上層引流不足，水池正在枯竭。
- ❌ **把測試預算混進主力評估**：剛開的小額測試組數據還不穩，別跟成熟主力組放一起比。

## 第 2 層 · 表現層：四個指標的健康區間

結構沒問題後，逐組看指標健不健康。

### 2-1 健康 vs 警戒區間

| 指標 | 健康區間（還在賺錢） | 警戒區間（該動手了） |
|---|---|---|
| ROAS | ≥ 3× | < 2× |
| CTR | 1–2% | 連 3 天下滑 |
| CVR | 2–5% | 明顯低於基準 |
| CPA | 低於目標 110% | > 目標 130% |

> ⚠️ **健康區間因產業而異**——這張表是電商起點值。記下你過去 3 個月的平均，那才是你的基準線。先在 [`../prompts/my-standards-template.md`](../prompts/my-standards-template.md) 寫下自己的數字。跨市場對照值見 [`benchmarks.md`](benchmarks.md)。

### 2-2 ROAS 目標怎麼定：看毛利，不看別人

ROAS 目標不是抄來的，是從毛利倒推的打平點：**打平 ROAS = 1 ÷ 毛利率**。

| 毛利率 | 打平 ROAS | 建議目標 |
|---|---|---|
| 30% | 3.3× | ≥ 4× |
| 40% | 2.5× | ≥ 3× |
| 50% | 2.0× | ≥ 2.5× |

低於打平點＝賠錢賺曝光。完整對照表見 [`../prompts/my-standards-template.md`](../prompts/my-standards-template.md)。

### 2-3 ⭐ 指標互相矛盾時的診斷矩陣（這層最值錢的部分）

單一指標好壞看不出根因，**兩個指標一起看才知道問題在哪**。這是資深投手和新手最大的差距：

| 現象 | 可能的根因 | 該往哪動 |
|---|---|---|
| CTR 高 + CVR 低 | 素材吸到人，但**落地頁／價格／受眾接不住**；或素材誇大引來不對的人 | 改落地頁、檢查價格期待落差，而非改素材 |
| CTR 低 + CVR 高 | 素材不吸睛，但點進來的人很精準 | **換更吸睛的素材擴量**，受眾是對的別動 |
| CTR 高 + CPA 高 | 點很多但沒轉換，流量品質差或落地頁漏水 | 查落地頁載入、表單流程、結帳卡點 |
| ROAS 高 + 花費低 | 一塊小而美的金礦，沒餵飽 | **加碼**（mROAS 通常還很高） |
| ROAS 高 + 花費已高 | 可能接近飽和 | 小幅試加，看 mROAS 是否還在；別暴衝 |
| CPM 飆高 + Frequency 高 | 受眾太窄、一直重複觸及同一群人 → 素材疲乏 | 擴受眾或換素材 |
| CPM 飆高 + Frequency 正常 | 競爭變激烈、或廣告分數低 | 提升素材互動率、檢查廣告品質 |
| CVR 突然跌 + 其他不變 | 落地頁壞了／缺貨／追蹤碼掉了 | **先查技術面**，不是廣告問題 |

> 用法：先找出「異常的指標」，再看「它旁邊的指標」，對照這張表推根因。**90% 的「ROAS 掉了怎麼辦」都能在這裡找到方向。**

### 2-4 樣本量：別被小數字騙了

- 轉換數 **< 30** 的組別，任何結論都「僅供參考」——3 轉換變 1 轉換，CPA 看起來爆掉，但可能只是運氣。
- 統計上，要看出兩組真有差異，每組通常需要**累積足夠轉換**（電商常用 50–100 作門檻）。
- 對策：小樣本組**先別下激烈決策**，標「樣本不足，再觀察」，或拉長觀察區間累積數據。

## 第 3 層 · 趨勢層：3／7／14 天的訊號

表現層看的是「現在好不好」，趨勢層看的是「**往哪個方向走、是真的還是雜訊**」。

### 3-1 三個時間窗各代表什麼

| 時間窗 | 代表 | 看什麼 |
|---|---|---|
| 3 天 | 短期波動 | 素材剛上線的初步反應 |
| 7 天 | 穩定性 | 廣告組合是否站穩 |
| 14 天 | 長期趨勢 | 帳戶整體有無衰退 |

**對比觀察**：短跌長穩 = 波動；長跌 = 真衰退。

> **關鍵原則**：單看某一段容易被雜訊誤導。3 天、7 天、14 天三段**同向**時，才是值得行動的真趨勢。

### 3-2 ⚠️ 兩個會讓你誤判的陷阱：學習期 與 破壞效應

趨勢層最常見的錯，是把「系統還沒算完」當成「成效變差」。看到這兩個現象，先按兵不動，不要照普通標準下激烈決策：

**① 學習期（Learning Phase）**
廣告組合**剛建立、或剛做重大編輯**後，Meta 需要約 50 次轉換事件、通常 3–7 天來重新學習投放對象。學習期內 CPA 會偏高、數據劇烈跳動，這是正常的，不是衰退。

- 剛上線 < 3 天的素材／廣告組合 → 標「學習期，暫不評斷」，給它時間。
- 學習期內看到 ROAS 掉，**不要**急著減碼或關閉——你可能砍掉一組其實會成功的廣告。

**② 破壞效應（Breakdown / Edit Effect）**
**每次重大編輯都會把廣告組合打回學習期重新計算**。重大編輯包括：改預算（尤其 ±20% 以上）、改受眾、改出價策略、改素材、改最佳化目標。

- 後果：你昨天「加碼 30%」這個動作本身，就會讓今天的數據變差幾天——這是編輯造成的，不是廣告變爛。
- 對策：**一次只改一個變數**，改完後給 3–7 天緩衝再評斷，別當天看到掉量又馬上改回去（改回去＝又一次破壞效應，惡性循環）。
- 小額、漸進調整（一次 ±20% 內）比暴力大改更不容易觸發重新學習。

> 一句話：**「最近有沒有動過它」比「數據好不好看」更該先問。** 動過，就先讓子彈飛幾天。

### 3-3 其他雜訊來源（別當成趨勢）

- **檔期效應**：母親節後第一週掉量是自然回落，不是衰退。把檔期寫進情境補充。
- **週期性**：B2B 週末掉、電商發薪日／週五晚上漲，是日常節律，要比「同類日」而非「昨天 vs 今天」。
- **單日異常**：平台當機、新聞洗版、競品大促，可能造成單日尖刺，用 3 天平滑掉。

## 第 4 層 · 決策層：四個行動的判斷準則

前三層都是診斷，這層是處方。

### 4-1 四個動作與觸發條件

| 行動 | 觸發條件 | 動作幅度 |
|---|---|---|
| **加碼** | 連續 7 天 ROAS > 目標且預算未滿、mROAS 仍健康 | +20–30% 預算，測試極限 |
| **維持** | 各項指標在健康區間波動 | 保持原樣，別亂動 |
| **減碼** | 連續 7 天 ROAS < 目標 80% | 先砍 30–50% 預算止血再觀察 |
| **關閉** | 連續 14 天 ROAS < 1×、CPA > 目標 200% | 直接關掉這組 |

### 4-2 決策樹（照著走，不會卡）

```
這組廣告 →
  1. 最近 7 天內有重大編輯過嗎？
      是 → 標「緩衝期」，本輪不動它，等滿 3–7 天。
      否 → 往下。
  2. 轉換數夠嗎（≥ 30）？
      否 → 標「樣本不足」，再觀察或拉長區間。
      是 → 往下。
  3. ROAS 在哪個區間？（對照你的目標）
      ≥ 目標、預算未滿、mROAS 健康 → 【加碼 +20–30%】
      在健康區間波動            → 【維持】
      < 目標 80%，連 7 天        → 【減碼 -30~50%】
      < 1× 且 CPA > 目標 200%，連 14 天 → 【關閉】
  4. 動作確定後 → 一次只改這一個變數，記錄今天改了什麼，3–7 天後再評。
```

### 4-3 優先級：先救火，再加碼

決策清單要排序，不是平均用力：

- **P0 立即處理**：正在嚴重虧損／純燒錢（ROAS < 1×、0 轉換還在花錢）。每多跑一天就多虧一天。
- **P1 本日處理**：明確該減碼或該加碼的組（影響大盤的主力）。
- **P2 觀察**：學習期、樣本不足、邊緣案例，標問號下午或隔天再看。

> 順序心法：**先止血（關掉燒錢的）→ 再搬錢（砍下來的預算挪給高效組）→ 最後微調**。同一筆預算，從 ROAS 0.8× 的組搬到 ROAS 11× 的組，效益遠大於把好的調更好。

### 4-4 動作幅度為什麼是 ±20–30%，不是 ±100%

因為**破壞效應**（見 3-2）。一次大改會觸發重新學習，反而打亂成效。漸進調整讓系統平穩過渡，也讓你看得出「是這次調整的功勞，還是別的因素」。想加到兩倍？分 3–4 次、每次 +30%、中間隔 3–7 天，比一次拉滿穩得多。

## 五、把四層串起來：5 分鐘決策工作流

| 時間 | 動作 | 對應層 |
|---|---|---|
| 9:00 | 匯出近 7 天 CSV（以廣告組合為單位） | 資料準備 |
| 9:02 | 貼進 AI 建議器（System + User Prompt） | — |
| 9:03 | 看「結構快檢 + 行動清單」 | 全四層 |
| 9:04 | 依優先級勾選，沒共識的標問號 | 決策層 |
| 9:05 | 進後台執行，記錄「今天改了什麼」 | 立即行動 |

> 記錄「今天改了什麼」是隱藏關鍵——明天看數據時，這就是判斷「是不是破壞效應」的依據。

## 六、為什麼這套邏輯能讓 AI 像資深投手

- **邏輯具體，不憑感覺**：每個建議都附判斷依據（哪一層、什麼數字觸發），AI 才不會幻覺。
- **可被驗證**：決策邏輯看得到「為什麼」，可以被追問、被討論、被推翻。
- **可規模化**：同一套框架，不同帳戶、不同產業都能跑。
- **可調整**：把你的個人標準寫進 Prompt，越用越聰明。

## 七、人與 AI 的分工

| 面向 | AI 能做（交給自動化） | 需要你（人的判斷） |
|---|---|---|
| 數據整理 | 彙整 CSV、計算指標、標出異常值 | 確認資料正確、設定 ROAS／CPA 目標 |
| 趨勢判讀 | 比對 3／7／14 天、找出偏離訊號 | 判斷是真趨勢，還是學習期／檔期雜訊 |
| 給建議 | 產出可執行清單、排出優先順序 | 拍板加碼／減碼／關閉，負最終成敗 |
| 重複工作 | 固定格式輸出、24 小時不喊累 | 設計流程、持續累積產業知識庫 |
| 創意情境 | 發想素材方向、提供文案草稿 | 理解品牌與客戶、最終定調拍板 |

**一句話記住：AI 給草稿，你給定論——判斷與責任永遠是人的事。**

## 一頁速查表

> 印出來貼牆上。每天看報表時，從上往下問一遍。

```
【結構層】錢分得對不對？
  □ 有沒有任一組 > 50% 預算？（過度集中要查）
  □ 引流/轉換/再行銷/回購 四階段都有錢嗎？
  □ 再行銷佔比 > 30%？（小心水池枯竭）

【表現層】指標健不健康？（對照「我的標準」）
  □ ROAS ≥ 目標？CTR 1–2%？CVR 2–5%？CPA < 目標110%？
  □ 指標互相矛盾 → 查診斷矩陣找根因
  □ 轉換數 < 30 → 樣本不足，先別下激烈決策

【趨勢層】是真趨勢還是雜訊？
  □ 3/7/14 天三段同向嗎？
  □ 最近 7 天內動過它嗎？→ 學習期/破壞效應，先別動
  □ 是檔期/週期/單日異常造成的嗎？

【決策層】哪組加/維/減/關？
  □ 走一遍決策樹
  □ 排優先級：先止血 → 再搬錢 → 最後微調
  □ 一次只改一個變數，幅度 ±20–30%，記錄今天改了什麼

【鐵則】AI 給方向，人做決策；採納前回後台核對原始數據。
```
