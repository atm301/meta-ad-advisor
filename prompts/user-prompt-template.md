# User Prompt 模板：四段資料 + 行動清單格式

> 貼完 [System Prompt](system-prompt.md) 後，接著貼這段，並把方括號 `[ ]` 內換成你自己的資料。

---

```
請依四層判斷法分析以下廣告數據，輸出行動清單。

【① 資料區間】
過去 7 天（[2026-XX-XX] 至 [2026-XX-XX]），對照前 7 天。
（若只有單期資料，就說明「僅單期，趨勢層請標註資料不足」）

【② 資料表格】
以下為廣告組合層級的 CSV，欄位為：活動名稱,花費,曝光,點擊,轉換,轉換金額,目標客群,版位

活動名稱,花費,曝光,點擊,轉換,轉換金額,目標客群,版位
[把你的 CSV 內容貼在這裡，一列一組廣告]


【③ 我的標準】
- ROAS 目標：[例如 3.0×]
- CPA 目標：[例如 NT$400]
- 單日總預算上限：[例如 NT$50000]
- 健康區間（若與預設不同請寫明）：[例如 CTR 健康 ≥ 1.5%]

【④ 情境補充】
[寫下這期的背景，例如：]
- 檔期：[母親節檔期第 2 週／無檔期]
- 素材：[受眾 A 三天前剛換新素材]
- 受眾：[上週剛擴 LAL 3% 新受眾]
- 其他：[庫存即將出清／新品上市第一週]

請依 System Prompt 定義的格式輸出。
```

---

## 填寫提示

- **資料區間**寫清楚才有趨勢可言。沒有對照期就老實說，AI 會把趨勢層標成「資料不足」而不是瞎掰。
- **我的標準**是整套框架的靈魂。同樣 ROAS 2.5×，目標 2× 是達標、目標 4× 是警戒——沒有目標，AI 只能用通用基準猜。第一次先用 [`my-standards-template.md`](my-standards-template.md) 把自己的數字定下來，之後每次沿用。
- **情境補充**能擋掉很多誤判。剛換素材的學習期掉量、檔期結束的自然回落，都是情境，不是衰退。
