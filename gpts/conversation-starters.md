# GPTs 對話起始句

把這 4 句填到 GPTs 設定的「Conversation starters」欄位，使用者點一下就能開始。

---

```
分析我這 7 天的廣告數據，給我加碼／減碼／關閉清單
```

```
我的 ROAS 連兩天下滑，幫我找出是哪幾組廣告拖累的
```

```
我的預算 70% 壓在再行銷，幫我看結構分配合不合理
```

```
教我怎麼匯出 Meta 廣告 CSV，要哪些欄位
```

---

## 設計邏輯

- 第 1 句是主功能入口（完整分析）。
- 第 2 句對應「找不到原因」痛點（趨勢層）。
- 第 3 句對應「結構過度集中」（結構層）。
- 第 4 句幫完全新手解決「資料怎麼準備」的卡關。

可依你的產業換成更貼近的情境，例如把「再行銷」換成你實際的主力受眾名稱。
